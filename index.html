FAQ

Is it really 4x faster?

Yes! Traditional extension downloaders are limited to 6-8 concurrent connections and single-threaded OPFS writes. MuxNet uses 32 parallel workers with SharedArrayBuffer for zero-copy transfers, achieving 30-50 MB/s vs 8-12 MB/s.

Does it upload my videos to a server?

No. MuxNet is 100% client-side. All processing happens in your browser using Web Workers and FFmpeg.wasm. Nothing is uploaded anywhere.

Why does it need FFmpeg.wasm?

HLS streams have separate video and audio tracks that need to be muxed (merged) with proper timestamp synchronization. FFmpeg.wasm provides real packet-level muxing for perfect A/V sync.

What's the file size limit?

No hard limit. MuxNet uses streaming writes, so it never loads the entire file into RAM. We've tested with 10+ GB files successfully.

Can I use it without the extension?

Yes! You can manually provide segment URLs directly to muxnet.app/download. The extension just makes detection easier.

Is it open source?

Yes! MuxNet is MIT licensed. Check out the GitHub repo to contribute or self-host.
